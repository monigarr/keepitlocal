# Keep It Local — Source Ranking

**Framework component:** Methodology
**Canonical reference:** Source hierarchy for the [Evidence Standard](EVIDENCE_STANDARD.md)

---

## Purpose

When multiple sources are available, this ranking defines which sources to prefer for confirming facts. It supports the [Evidence Standard](EVIDENCE_STANDARD.md) and the [Research Method](RESEARCH_METHOD.md).

## The ranking

| Rank | Source category | Examples |
| --- | --- | --- |
| 1 | Law / regulation / official government record | Statutes, regulations, Executive Orders, agency orders, official determinations, public regulatory filings |
| 2 | Official technical / infrastructure record | Utility filings, transmission studies, interconnection documents, engineering reports, environmental documents, planning-board records |
| 3 | Indigenous-government source | Official Indigenous-government statements, resolutions, consultation documents, technical reports |
| 4 | Project / developer primary source | Project presentations, site plans, environmental submissions, corporate filings, official project websites, statements by project representatives |
| 5 | Credible secondary reporting | Established news organizations, recognized trade publications, academic reporting, professional organizations |
| 6 | Community / public discussion | Public meetings, community organizations, public comments, social-media discussion |

## How to use the ranking

### Primary-source preference

Prefer the highest-ranking source practical for **confirming facts**. Primary sources (ranks 1–4) directly establish claims. Secondary reporting (rank 5) provides useful context but should not silently replace primary evidence when primary evidence is available.

### Community sources are still valuable

A lower rank does not mean a source is useless.

Community and public discussion (rank 6) is often where questions and leads originate. It identifies:

- what to investigate;
- what a community is hearing and experiencing;
- what questions deserve formal research.

Community sources should be used to **generate questions and leads**, not treated automatically as factual evidence.

### Label whose position it is

When documenting a statement, identify whose position it represents:

- an Indigenous government;
- an individual community member;
- a municipal or state government;
- a federal government;
- a developer or project representative;
- a utility;
- an independent analyst.

Never collapse these into a single "community position."

### Conflicting sources

When credible sources conflict:

1. Identify the disagreement rather than silently choosing a preferred source.
2. Check whether the sources are measuring the same thing.
3. Prefer primary records where available.
4. Preserve unresolved disagreement.
5. Update when authoritative evidence clarifies the issue.

## Relationship to evidence classification

Source rank describes *where* information comes from.

Evidence classification describes *what the evidence establishes*:

| Classification | Meaning |
| --- | --- |
| **CONFIRMED** | Supported by a primary or authoritative source |
| **REPORTED** | From credible secondary reporting, not independently verified |
| **INFERRED** | Reasonable technical reasoning from documented information |
| **HYPOTHESIS** | Plausible but unverified |
| **UNKNOWN** | Not established by available evidence |

A primary source does not automatically make a claim correct, and a secondary source is not automatically wrong. The ranking governs preference; the [Evidence Standard](EVIDENCE_STANDARD.md) governs classification.

## Single sentence

> **Confirm facts with the highest-ranking source you can find; use community sources to find the questions.**
