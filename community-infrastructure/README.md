# Community Infrastructure

**Layer:** Applications
**Scope:** Reusable application domain for communities
**Research case:** [`research/EO_14420_14421/`](../research/EO_14420_14421/)

## What this directory is

This directory is a **reusable application domain**: the place where the Keep It Local framework is applied to the infrastructure dependencies that matter at community scale.

It is **not** an advocacy folder and **not** an Akwesasne political folder. It is a framework for any community to understand what it depends on.

## The framework question at community scale

> What does our community depend on? Who controls those dependencies? What happens when they fail? What can we keep, control, replace, export, recover, or operate locally?

## Dependency areas in scope

Communities typically depend on:

- electricity;
- water;
- telecommunications;
- internet;
- cloud services;
- data centers;
- transportation;
- emergency services;
- digital government;
- financial services;
- communications;
- critical suppliers.

Each can be analyzed with the same framework: identify the dependency, classify the evidence, position it in the [Infrastructure Stack](../models/infrastructure-stack.md), analyze failure modes and resilience, and ask who controls it.

## How to use this directory

1. Start from the [Dependency Model](../models/dependency-model.md) and the [Research Method](../methodology/RESEARCH_METHOD.md).
2. Classify evidence with the [Evidence Standard](../methodology/EVIDENCE_STANDARD.md).
3. Use the [Infrastructure Data Model](../models/infrastructure-data-model.md) to record what you find.
4. Apply the [Resilience Model](../models/resilience-model.md) and [Sovereignty Model](../models/sovereignty-model.md).
5. Keep findings in `research/`, keep framework material here.

## Discipline

Community infrastructure analysis must distinguish:

- what is documented;
- what is reported;
- what is inferred;
- what remains unknown.

It must also distinguish whose position is being recorded — an Indigenous government, an individual community member, a municipality, a utility, a developer, a federal government — and must not collapse them into one "community position."

See the [Evidence Standard](../methodology/EVIDENCE_STANDARD.md) for the governing rules.
