# Keep It Local — Architecture

This directory documents how Keep It Local works as a **reusable systems framework**.

| Document | Purpose |
| --- | --- |
| `KEEP_IT_LOCAL_SYSTEM_ARCHITECTURE.md` | Canonical system architecture: layer responsibilities, flow, and repository mapping. |
| `../README.md` | Nontechnical entry point to the project. |

## The framework in one line

> **Principles → Methodology → Models → Infrastructure → Applications → Research**

## How the layers relate

- **Principles** define what we care about (local control, sovereignty, resilience).
- **Methodology** defines how we know (evidence, research method, source ranking).
- **Models** define how we represent systems (dependency, infrastructure, resilience, sovereignty).
- **Infrastructure** provides practical tools for examining physical and digital systems.
- **Applications** show the framework being used at a scale (community, personal, organizational).
- **Research** applies the whole framework to real-world cases.

## Navigating

- Start at [`../README.md`](../README.md).
- Read the [system architecture](KEEP_IT_LOCAL_SYSTEM_ARCHITECTURE.md).
- Then follow the Methodology and Models directories in order.
