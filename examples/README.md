# Examples

**Layer:** Applications
**Purpose:** Demonstrate that the Keep It Local models are **reusable outside this repository**.

The acceptance criterion for the framework is simple: it must be possible to apply the models to another person, business, AI system, organization, or community **without rewriting the methodology**.

Each example here applies the canonical models directly:

- [Dependency Model](../models/dependency-model.md)
- [Infrastructure Stack](../models/infrastructure-stack.md)
- [Resilience Model](../models/resilience-model.md)
- [Sovereignty Model](../models/sovereignty-model.md)
- [Evidence Standard](../methodology/EVIDENCE_STANDARD.md)

## How to add an example

1. Choose one concrete system and one clear question.
2. Define the system boundary.
3. Inventory dependencies using the [Dependency Model](../models/dependency-model.md).
4. Classify every claim with the [Evidence Standard](../methodology/EVIDENCE_STANDARD.md) — **UNKNOWN is a valid result**.
5. Analyze failure, resilience, and control.
6. State open questions and next actions.

Do not multiply documents unnecessarily. One good worked example teaches more than five overlapping ones.
